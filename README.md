# ObjektRT.std

Welcome to the official ObjektRT standard library written in Contract.



## what is this for?
ObjektRT is a Runtime specification and Virtual machine, currently it's standard library is in C# which means that using it from ObjektRT's IL system is weird.
this means host languages (such as contract), can't quite use the built in standard library with ease.

## Why contract?

well, that's really the only high level language we have so far for ObjektRT.
